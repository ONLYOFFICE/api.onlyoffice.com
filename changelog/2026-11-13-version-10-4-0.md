## New features

- **Docs API**:
  - Added the [`document.options.watermark`](/docs/docs-api/usage-api/config/document/#optionswatermark) and [`document.options.watermark_on_draw`](/docs/docs-api/usage-api/config/document/#optionswatermark_on_draw) parameters: the watermark object, the `%user_name%` placeholder, opacity, watermarks in PDF and image downloads, and why a watermark is not access control.
  - Added the [Data retention](/docs/docs-api/get-started/how-it-works/data-retention) page: what ONLYOFFICE Docs keeps while documents are edited, where and for how long, who can access the cache, and how to delete it.
  - Added the [Server components](/docs/docs-api/get-started/how-it-works/#server-components) section to How it works: the DocService, FileConverter and Metrics processes, the external services they use, and the Node.js runtime bundled into the executables.
- **Common**:
  - Added an llms.txt link to the footer and named `/llms.txt` in the production robots.txt.
  - Added a megaphone icon to the announcement bar.

## Improvements

- **Docs API**:
  - Replaced the duplicated watermark rows in the conversion request table with a link to the watermark object.
  - Clarified on the Data retention page that cache folders created before a restart are left behind only in the Community edition.
- **Localization**:
  - Synced the zh-CN document config and conversion request pages with English.
  - Synced the zh-CN How it works and Data retention pages with English.

## Bugfixes

- Fixed the old help center `.aspx` links in the Docs API pages and connector guides.
- Fixed the Working with watermark sample controls: Apply stays disabled until the editor is ready, Enter applies the text, and every select is labelled.
- Fixed editor samples that never opened when they mounted while the Docs API script was still loading.
