## New features

- **Docs API**: Added missing formats to the [`document.fileType`](/docs/docs-api/usage-api/config/document#filetype) parameter.
- **Office API**: Updated the [Office API documentation](/docs/office-api/get-started/overview) for version 9.0.4.

## Improvements

- **Common**: Added the website [Changelog section](/changelog).
- **Docs API**:
  - Added GitHub links to each [language-specific example](/docs/docs-api/samples/language-specific-examples).
  - Added fonts information to the [Changing default fonts](/docs/docs-api/samples/language-specific-examples/changing-default-fonts#known-issues) page.
- **Plugins and macros**:
  - Updated documentation in Chinese.
  - Added pages with full [list of events](/docs/plugins/interacting-with-editors/document-api) to the **Interacting with editors** section.
