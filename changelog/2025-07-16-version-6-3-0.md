## New features

- **Docs API**: Updated the behavior of [`customization.macros`](/docs/docs-api/usage-api/config/editor/customization/customization-standard-branding#macros) — it now disables all macro-related functionality, including adding, editing, and execution.
- **Plugins and macros**:
  - Added the ability to add [asynchronous custom functions](/docs/macros/guides/adding-custom-functions#asynchronous-functions).
  - Added the ability to [automatically convert VBA code](/docs/macros/guides/converting-vba-macros#automatic-conversion-using-ai-plugin) into ONLYOFFICE macros using AI plugin.
  - Added the ability to [automatically generate ONLYOFFICE macros](/docs/macros/guides/writing-macros#generating-macros-using-ai-plugin) using AI plugin.
