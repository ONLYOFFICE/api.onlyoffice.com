## New features

- **Docs API**:
  - Added the [`document.options.watermark`](/docs/docs-api/usage-api/config/document/#optionswatermark) and [`document.options.watermark_on_draw`](/docs/docs-api/usage-api/config/document/#optionswatermark_on_draw) parameters: the watermark object, the `%user_name%` placeholder, opacity, watermarks in PDF and image downloads, and why a watermark is not access control.
  - Added the [Data retention](/docs/docs-api/get-started/how-it-works/data-retention) page: what ONLYOFFICE Docs keeps while documents are edited, where and for how long, who can access the cache, and how to delete it.
  - Added the [Server components](/docs/docs-api/get-started/how-it-works/#server-components) section to How it works: the DocService, FileConverter and Metrics processes, the external services they use, and the Node.js runtime bundled into the executables.
  - Added an [FAQ entry](/docs/docs-api/more-information/faq/integrating#onlyoffice-docs-cannot-download-a-file-from-my-server-that-uses-a-self-signed-certificate-what-should-i-do) on what to do when ONLYOFFICE Docs cannot download files from a server with a self-signed certificate, in any integration.
- **Common**:
  - Added an llms.txt link to the footer and named `/llms.txt` in the production robots.txt.
  - Added a megaphone icon to the announcement bar.

## Improvements

- **Docs API**:
  - Restructured the [ownCloud](/docs/docs-api/get-started/ready-to-use-connectors/owncloud-integration) and [Nextcloud](/docs/docs-api/get-started/ready-to-use-connectors/nextcloud-integration) known issues: self-signed certificates and the background connection check now sit under Checking the connection, file conversion has its own section, and each remaining issue has a heading.
  - Covered the ONLYOFFICE Docs side of self-signed certificates (`rejectUnauthorized`) and files shared without download permission on the ownCloud and Nextcloud pages, and file locking on the Nextcloud page.
  - Used the connectors' current UI names on the ownCloud and Nextcloud pages.
  - Removed the duplicated `watermark.*` rows from the conversion request table, which already links to the watermark object.
- **Localization**:
  - Synced the zh-CN ownCloud, Nextcloud, FAQ, document config, conversion request and How it works pages with English, and gave the zh-CN ownCloud, Nextcloud and How it works headings English anchors.
  - Translated the Data retention page and the Working with watermark and Opening the editor in a dialog samples.
