## New features

- **Plugins and macros**:
  - Added the [bundled plugin type](/docs/plugins/configuration/types/#background) description.
  - Added the ability to access [cell address information](/docs/macros/guides/adding-custom-functions/#accessing-cell-addresses) inside custom functions.

## Improvements

- **Common**: Restructured the [Changelog](/changelog) section.
- **Docs API**: Updated documentation in Chinese.
- **Plugins and macros**: Added the [AI plugin](/docs/ai/guides/ai-plugin) section.
