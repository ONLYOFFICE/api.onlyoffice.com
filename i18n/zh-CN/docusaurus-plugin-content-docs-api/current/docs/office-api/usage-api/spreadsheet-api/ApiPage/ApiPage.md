# ApiPage

表示工作表特定页面类型（偶数页或首页）的页眉和页脚的类。

## 属性

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| CenterFooter | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页脚中间部分。 |
| CenterHeader | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页眉中间部分。 |
| LeftFooter | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页脚左侧部分。 |
| LeftHeader | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页眉左侧部分。 |
| RightFooter | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页脚右侧部分。 |
| RightHeader | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页眉右侧部分。 |

| [GetRightHeader](./Methods/GetRightHeader.md) | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | 返回此页面类型的页眉右侧部分。 |
