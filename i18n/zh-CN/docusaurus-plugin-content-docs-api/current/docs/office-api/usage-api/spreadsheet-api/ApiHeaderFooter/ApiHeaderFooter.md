# ApiHeaderFooter

表示页面中单个页眉或页脚部分（左侧、中间或右侧）的类。

## 属性

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| Text | string | 返回或设置此页眉或页脚部分的文本（可包含 &P、&D 等格式代码）。 |

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetText](./Methods/GetText.md) | string | 返回此页眉或页脚部分的文本。 |
| [SetText](./Methods/SetText.md) | boolean | 设置此页眉或页脚部分的文本，同时保留其他两个部分。 |
