| [GetClassType](./Methods/GetClassType.md) | "hideShowAction" | 返回 ApiHideShowFormsAction 类的类型。 |
| [GetNames](./Methods/GetNames.md) | string[] | 获取要隐藏的字段名称 |
| [IsHide](./Methods/IsHide.md) | boolean | 检查操作是否隐藏字段 |
| [SetHide](./Methods/SetHide.md) | boolean | 设置操作是否隐藏字段 |
| [SetNames](./Methods/SetNames.md) | boolean | 设置要隐藏的字段名称 |
