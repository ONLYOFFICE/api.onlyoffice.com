# ApiJsAction

表示 JS 操作的类。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "jsAction" | 返回 ApiJsAction 类的类型。 |
| [GetScript](./Methods/GetScript.md) | string | 获取操作脚本 |
| [SetScript](./Methods/SetScript.md) | boolean | 设置操作脚本。 |
