# GetActionsJSON

获取 JSON 格式的所有字段操作。

:::note
此功能仅在 ONLYOFFICE Docs 付费版本中可用。
:::

继承自 [ApiBaseWidget.GetActionsJSON](../../ApiBaseWidget/Methods/GetActionsJSON.md)。

## 语法

```javascript
expression.GetActionsJSON();
```

`expression` - 表示 [ApiTextWidget](../ApiTextWidget.md) 类的变量。

## 参数

此方法没有任何参数。

## 返回值

JSON
