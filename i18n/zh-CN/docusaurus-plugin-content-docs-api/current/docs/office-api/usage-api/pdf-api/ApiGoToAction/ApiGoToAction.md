# ApiGoToAction

表示 GoTo 操作的类。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "goToAction" | 返回 ApiGoToAction 类的类型。 |
| [GetPage](./Methods/GetPage.md) | number | 获取目标页面索引 |
| [GetRect](./Methods/GetRect.md) | [Rect](../Enumeration/Rect.md) \| null \| undefined | 获取跳转目标矩形 |
| [GetType](./Methods/GetType.md) | [GoToType](../Enumeration/GoToType.md) | 获取跳转类型 |
| [GetZoom](./Methods/GetZoom.md) | number \| null \| undefined | 获取操作的缩放比例 |
| [SetPage](./Methods/SetPage.md) | boolean | 设置目标页面索引 |
| [SetRect](./Methods/SetRect.md) | boolean | 设置跳转目标矩形 |
| [SetType](./Methods/SetType.md) | boolean | 设置跳转类型 |
| [SetZoom](./Methods/SetZoom.md) | boolean | 设置跳转缩放比例 |
