# GetInternalId

返回当前注释的内部 ID。

:::note
此功能仅在 ONLYOFFICE Docs 付费版本中可用。
:::

继承自 [ApiBaseAnnotation.GetInternalId](../../ApiBaseAnnotation/Methods/GetInternalId.md)。

## 语法

```javascript
expression.GetInternalId();
```

`expression` - 表示 [ApiHighlightAnnotation](../ApiHighlightAnnotation.md) 类的变量。

## 参数

此方法没有任何参数。

## 返回值

string
