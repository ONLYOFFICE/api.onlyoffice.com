# ApiResetFormsAction

表示重置表单操作的类。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "resetFormsAction" | 返回 ApiResetFormsAction 类的类型。 |
| [GetNames](./Methods/GetNames.md) | string[] | 获取要重置的字段名称 |
| [IsAllExcept](./Methods/IsAllExcept.md) | boolean | 是否重置除指定名称字段以外的所有字段 |
| [SetAllExcept](./Methods/SetAllExcept.md) | boolean | 设置是否重置除指定名称字段以外的所有字段 |
| [SetNames](./Methods/SetNames.md) | boolean | 设置要重置的字段名称 |
