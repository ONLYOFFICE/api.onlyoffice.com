# ShadowSettings

用于创建阴影的属性。

## 类型

Object

## 属性

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| color | [ApiColor](../ApiColor/ApiColor.md) | 阴影颜色（默认为黑色）。 |
| offsetX | number | 阴影的水平偏移量，以磅为单位（正值向右偏移）。 |
| offsetY | number | 阴影的垂直偏移量，以磅为单位（正值向下偏移）。 |
| rotateWithShape | boolean | 指定阴影是否随形状一起旋转。 |
| size | number | 阴影大小，以形状大小的百分比表示。 |
| transparency | number | 阴影透明度，范围从 0.0（不透明）到 1.0（透明）。 |
