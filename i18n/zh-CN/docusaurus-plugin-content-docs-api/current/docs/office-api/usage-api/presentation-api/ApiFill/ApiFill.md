# ApiFill

表示填充基类的类。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "fill" | 返回 ApiFill 类的类型。 |
| [GetColor](./Methods/GetColor.md) | [ApiColor](../ApiColor/ApiColor.md) \| null \| undefined | 返回纯色填充的颜色。 |
| [GetTransparent](./Methods/GetTransparent.md) | number | 返回填充的透明度。 |
| [GetType](./Methods/GetType.md) | [FillType](../Enumeration/FillType.md) | 获取填充类型。 |
| [SetTransparent](./Methods/SetTransparent.md) | boolean | 设置填充的透明度。 |
