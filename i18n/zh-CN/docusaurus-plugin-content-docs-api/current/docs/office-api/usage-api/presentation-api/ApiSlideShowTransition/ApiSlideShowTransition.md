# ApiSlideShowTransition

表示幻灯片放映切换效果的类。

## 属性

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| AdvanceOnClick | boolean | 返回或设置是否在单击鼠标时切换幻灯片。 |
| AdvanceOnTime | boolean | 返回或设置是否在指定时间后切换幻灯片。 |
| AdvanceTime | number \| undefined | 返回或设置幻灯片切换时间（以毫秒为单位）。 |
| Duration | number | 返回或设置切换效果的持续时间（以毫秒为单位）。 |
| EntryEffect | [EntryEffect](../Enumeration/EntryEffect.md) | 返回或设置幻灯片放映切换的进入效果。 |
| Speed | [TransitionSpeed](../Enumeration/TransitionSpeed.md) | 返回或设置切换速度。 |
