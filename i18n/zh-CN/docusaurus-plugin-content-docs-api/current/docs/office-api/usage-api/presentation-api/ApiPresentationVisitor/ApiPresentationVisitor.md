# ApiPresentationVisitor

表示演示文稿访问器的类。它会遍历幻灯片、版式、母版、演讲者备注、绘图对象（包括嵌套在组合、表格单元格和图表标题中的绘图对象）及其文本的段落和文本块。为钩子分配函数即可接收通知；从钩子返回 true 可跳过该节点的子树。

:::note
此功能仅在 ONLYOFFICE Docs 付费版本中可用。
:::

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [Stop](./Methods/Stop.md) | boolean | 停止遍历。当前钩子函数返回后不再调用其他钩子函数。 |
| [Traverse](./Methods/Traverse.md) | boolean | 遍历创建访问者时所基于的对象，并为每个节点调用已指定的钩子函数。 |
