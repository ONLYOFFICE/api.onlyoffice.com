# ApiStyle

表示样式的类。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "style" | 返回 ApiStyle 类的类型。 |
| [GetName](./Methods/GetName.md) | string | 返回当前样式的名称。 |
| [GetTablePr](./Methods/GetTablePr.md) | [ApiTablePr](../ApiTablePr/ApiTablePr.md) \| null \| undefined | 返回当前样式的表格属性。 |
| [GetType](./Methods/GetType.md) | [StyleType](../Enumeration/StyleType.md) | 返回当前样式的类型。 |
| [SetName](./Methods/SetName.md) | boolean | 为当前样式设置名称。 |
| [SetTablePr](./Methods/SetTablePr.md) | [ApiStyle](../ApiStyle/ApiStyle.md) | 设置当前样式的表格属性。 |
