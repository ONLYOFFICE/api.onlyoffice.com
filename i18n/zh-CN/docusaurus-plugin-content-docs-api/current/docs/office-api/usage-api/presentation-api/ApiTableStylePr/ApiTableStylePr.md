# ApiTableStylePr

表示一组格式属性的类，这些属性将有条件地应用于表格中符合 `Type` 所指定要求的部分。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "tableStylePr" | 返回 ApiTableStylePr 类的类型。 |
| [GetTablePr](./Methods/GetTablePr.md) | [ApiTablePr](../ApiTablePr/ApiTablePr.md) | 返回将应用于表格中符合条件格式类型的所有区域的表格属性集。 |
| [GetType](./Methods/GetType.md) | [TableStyleOverrideType](../Enumeration/TableStyleOverrideType.md) | 返回当前表格条件样式的类型。 |
| [SetTablePr](./Methods/SetTablePr.md) | boolean | 设置当前表格样式属性的表格属性。 |
