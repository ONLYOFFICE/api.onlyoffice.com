# ApiCustomProperties

表示文档自定义属性的类。

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [Add](./Methods/Add.md) | boolean | 使用自动类型检测向文档添加自定义属性。 |
| [Get](./Methods/Get.md) | string \| number \| Date \| boolean \| null | 根据名称返回自定义属性的值。 |
| [GetClassType](./Methods/GetClassType.md) | "customProperties" | 返回 ApiCustomProperties 类的类型。 |
