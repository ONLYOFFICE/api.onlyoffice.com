# ComparisonPr

文档比较和合并属性。

## 类型

Object

## 属性

| 名称 | 类型 | 描述 |
| ---- | ---- | ----------- |
| authorName | string | 修订所归属的名称。如果未指定，则使用第二个文档的作者。 |
| caseChanges | boolean | 指定是否标记大小写差异。 |
| comments | boolean | 指定是否比较批注中的差异。 |
| footnotes | boolean | 指定是否比较脚注和尾注中的差异。 |
| formatting | boolean | 指定是否标记格式差异。 |
| headersAndFooters | boolean | 指定是否比较页眉和页脚中的差异。 |
| tables | boolean | 指定是否比较表格中的差异。 |
| textBoxes | boolean | 指定是否比较文本框中的差异。 |
| whiteSpace | boolean | 指定是否标记空白差异。 |
| words | boolean | 指定按字词（true）还是按字符（false）跟踪更改。 |
