# ApiTablesOfFigures

表示文档中所有图表目录集合的类。

:::note
此功能仅在 ONLYOFFICE Docs 付费版本中可用。
:::

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [Add](./Methods/Add.md) | [ApiTableOfFigures](../ApiTableOfFigures/ApiTableOfFigures.md) \| null | 向文档添加图表目录并返回该图表目录。 |
| [GetClassType](./Methods/GetClassType.md) | "tablesOfFigures" | 返回 ApiTablesOfFigures 类的类型。 |
| [GetCount](./Methods/GetCount.md) | number | 返回文档中图表目录的数量。 |
| [GetItem](./Methods/GetItem.md) | [ApiTableOfFigures](../ApiTableOfFigures/ApiTableOfFigures.md) \| null | 返回集合中指定位置的图表目录。 |
| [GetParent](./Methods/GetParent.md) | [ApiDocument](../ApiDocument/ApiDocument.md) | 返回拥有此集合的文档。 |
