# ApiTableOfContents

表示目录的类。

:::note
此功能仅在 ONLYOFFICE Docs 付费版本中可用。
:::

## 方法

下表列出了可用的方法。

| 方法 | 返回值 | 描述 |
| ------ | ------- | ----------- |
| [Delete](./Methods/Delete.md) | boolean | 从文档中移除目录。 |
| [GetClassType](./Methods/GetClassType.md) | "tableOfContents" | 返回 ApiTableOfContents 类的类型。 |
| [GetIncludePageNumbers](./Methods/GetIncludePageNumbers.md) | boolean | 返回目录中是否显示页码。 |
| [GetLowerHeadingLevel](./Methods/GetLowerHeadingLevel.md) | number | 返回目录中包含的最低（最内层）标题级别。 |
| [GetParent](./Methods/GetParent.md) | [ApiDocument](../ApiDocument/ApiDocument.md) \| null | 返回包含该目录的文档。 |
| [GetRange](./Methods/GetRange.md) | [ApiRange](../ApiRange/ApiRange.md) \| null | 返回覆盖整个目录的范围。 |
| [GetRightAlignPageNumbers](./Methods/GetRightAlignPageNumbers.md) | boolean | 返回目录中的页码是否右对齐。 |
| [GetUpperHeadingLevel](./Methods/GetUpperHeadingLevel.md) | number | 返回目录中包含的最高（最外层）标题级别。 |
| [GetUseHyperlinks](./Methods/GetUseHyperlinks.md) | boolean | 返回条目是否设置为超链接格式。 |
| [SetIncludePageNumbers](./Methods/SetIncludePageNumbers.md) | boolean | 指定是否在目录中显示页码。 |
| [SetLowerHeadingLevel](./Methods/SetLowerHeadingLevel.md) | boolean | 设置目录中包含的最低（最内层）标题级别。 |
| [SetPr](./Methods/SetPr.md) | boolean | 将指定属性应用于目录并重新生成目录。 |
| [SetRightAlignPageNumbers](./Methods/SetRightAlignPageNumbers.md) | boolean | 指定目录中的页码是否右对齐。 |
| [SetUpperHeadingLevel](./Methods/SetUpperHeadingLevel.md) | boolean | 设置目录中包含的最高（最外层）标题级别。 |
| [SetUseHyperlinks](./Methods/SetUseHyperlinks.md) | boolean | 指定是否将条目设置为超链接格式。 |
| [Update](./Methods/Update.md) | boolean | 更新目录。 |
