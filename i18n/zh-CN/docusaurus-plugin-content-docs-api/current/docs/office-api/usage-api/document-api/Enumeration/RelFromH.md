# RelFromH

用于计算对象相对水平定位的基准的可能值。

## 类型

枚举

## 值

- "character"
- "column"
- "insideMargin"
- "leftMargin"
- "rightMargin"
- "margin"
- "outsideMargin"
- "page"

## 示例

将绘图相对于页面水平居中。

```javascript editor-docx
// How do I center a drawing horizontally relative to the page?

// Set a drawing horizontal aligment.

drawing.SetHorAlign("page", "center");
```
