# 概述

**Office API** 可让您快速轻松地将内容插入文档并按需设置格式。任何文档都是一个复合对象：由较大的节点（段落和表格）组成的树，您可以在其中插入较小的文档元素（文本块、图像、图表、形状）。

Office API 是用于操作文档编辑器的 JavaScript 库。它包含适用于各种文档类型的类和方法：[文档 API](../usage-api/document-api/document-api.md)、[电子表格 API](../usage-api/spreadsheet-api/spreadsheet-api.md)、[演示文稿 API](../usage-api/presentation-api/presentation-api.md)、[表单 API](../usage-api/form-api/form-api.md) 和 [PDF API](../usage-api/pdf-api/pdf-api.md)。

## 使用场景

以下是 Office API 的一些使用场景：

- 在插件代码 `.js` 文件中使用 Office API 构建[插件](../../plugins/interacting-with-editors/overview/overview.md)，以与编辑器内容和 Web 服务进行交互；
- 使用 JavaScript 语法和 Office API 脚本规范编写[宏](../../macros/guides/getting-started.md)；
- 在 [Document Builder 脚本](../../document-builder/get-started/overview.md)中使用 Office API 生成文档；
- 通过 [Automation API](../../docs-api/usage-api/automation-api/automation-api.md) 连接器从您自己的界面与编辑器内容进行交互，仅适用于 **ONLYOFFICE 文档开发者版**。
