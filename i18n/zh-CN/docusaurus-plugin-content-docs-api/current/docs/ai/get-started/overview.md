# 概述

AI 工具将 ONLYOFFICE 编辑器连接到 AI 提供商（例如 OpenAI 或 DeepSeek），或连接到在您自己的服务器上运行的模型。它为文档、电子表格、演示文稿和 PDF 编辑器提供 AI 聊天、摘要、翻译、语法和拼写检查、快速 AI 操作、AI 助手以及嵌入式 AI 智能体。

:::note
AI 工具不再支持添加自定义工具函数。如需调整 AI 工具的工作方式，请使用下列指南中介绍的设置、自定义提供商和 MCP 服务器。
:::

## 您可以做什么 {#what-you-can-do}

- **[配置 AI 工具](../guides/ai-plugin.md)**：连接 AI 模型、为任务分配模型，以及添加 MCP 服务器和网络搜索。
- **[为所有用户配置 AI 提供商](../guides/server-ai-providers.md)**：在管理面板中统一连接模型，用户无需任何设置。
- **[添加自定义提供商](../guides/custom-providers.md)**：连接列表中没有的提供商。
- **[使用 AI 智能体](../guides/ai-agent.md)**：直接在文档中通过自然语言命令执行编辑任务。
- **[转换 VBA 宏](../guides/converting-vba-macros.md)**：借助 AI 工具将 VBA 代码转换为 JavaScript 宏。
- **[使用 Ollama 运行本地模型](../guides/configuring-ollama-with-cors.md)**：让请求保留在您自己的计算机或服务器上。
