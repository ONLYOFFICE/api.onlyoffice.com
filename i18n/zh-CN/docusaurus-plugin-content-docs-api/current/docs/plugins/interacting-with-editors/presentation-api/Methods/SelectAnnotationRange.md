# SelectAnnotationRange

使用给定批注在演示文稿中选择文本。

:::note
此功能在 ONLYOFFICE Docs 付费版本中可用。
:::

## 语法

```javascript
expression.SelectAnnotationRange(annotation);
```

`expression` - 表示 [Api](../presentation-api.md) 类的变量。

| **名称** | **必需/可选** | **数据类型** | **默认值** | **描述** |
| ------------- | ------------- | ------------- | ------------- | ------------- |
| annotation | 必需 | Object |  | 注解选择对象。 |

## 返回值

此方法不返回任何数据。
