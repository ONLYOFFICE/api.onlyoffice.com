# RemoveAnnotationRange

从演示文稿中移除特定的批注范围。

:::note
此功能在 ONLYOFFICE Docs 付费版本中可用。
:::

## 语法

```javascript
expression.RemoveAnnotationRange(annotation);
```

`expression` - 表示 [Api](../presentation-api.md) 类的变量。

## 参数

| **名称** | **必需/可选** | **数据类型** | **默认值** | **描述** |
| ------------- | ------------- | ------------- | ------------- | ------------- |
| annotation | 必需 | Object |  | 注解移除对象。 |
| annotation.all | 可选 | boolean | false | 用于移除当前段落所有批注的标志。 |

## 返回值

此方法不返回任何数据。
