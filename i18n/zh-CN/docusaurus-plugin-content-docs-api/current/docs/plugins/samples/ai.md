# AI

将 AI 提供商（如 OpenAI、DeepSeek）接入 ONLYOFFICE 编辑器，实现智能文本生成、编辑、摘要提取及宏自动创建功能。

**支持的编辑器：** 文档、电子表格、演示文稿、PDF。

AI 插件现已更名为 **AI 工具**。有关 AI 工具的安装、配置和使用方法，请参阅 [AI 工具](../../ai/guides/ai-plugin.md)。AI 工具与其他插件分开开发，其源代码不公开。

[旧版 AI 插件](https://github.com/ONLYOFFICE/onlyoffice.github.io/tree/master/sdkjs-plugins/content/ai)已不再受支持，仅可在 9.4 版本中安装。
