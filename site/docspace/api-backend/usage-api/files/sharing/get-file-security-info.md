# getFileSecurityInfo

> FileShareArrayWrapper getFileSecurityInfo(id, count, startIndex)

`GET /api/2.0/files/file/{id}/share`

Get file sharing rights

Returns the accounts and groups that have access to a file, with the access level of each. The owner comes first, and accounts that have not accepted their invitation come last. The list has no external links of the file. To read them, use `GET api/2.0/files/file/{id}/links`. The list of a PDF form in a form-filling room ends with the room's external link, if any. Any signed-in user can call it, except a guest. A guest gets 403. A caller who cannot read the file also gets 403. A caller who can read the file but not change its access gets an empty list. The total in the response headers still counts the hidden entries. Inside a public room, read access is enough. The call is read-only. Use `startIndex` and `count` to page through the list. The response headers carry the total. A `count` out of range returns 400. If the file does not exist, the call returns 404. To read several entries in one call, use `POST api/2.0/files/share`.
