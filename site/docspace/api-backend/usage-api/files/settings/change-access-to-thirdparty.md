# changeAccessToThirdparty

> BooleanWrapper changeAccessToThirdparty(SettingsRequestDto)

`PUT /api/2.0/files/thirdparty`

Change the third-party settings access

Turns the connection of third-party storages on or off for the whole portal. It returns the value that is now stored. Requires a DocSpace admin. Other callers get 403. The call changes data, and you can repeat it with the same body. While the setting is off, `POST api/2.0/files/thirdparty` returns 403. Reading a folder of a connected storage also returns 403, but the connections stay. After the setting is turned on again, they work again. To list the storages the portal offers, use `GET api/2.0/files/thirdparty/capabilities`.
