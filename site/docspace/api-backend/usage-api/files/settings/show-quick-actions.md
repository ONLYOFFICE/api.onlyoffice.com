# showQuickActions

> BooleanWrapper showQuickActions(SettingsRequestDto)

`PUT /api/2.0/files/showquickactions`

Display quick actions

Turns the quick action buttons next to file names on or off for the calling account. Any signed-in user can call it. The call changes data, and you can repeat it with the same body. An account that never set the value has the buttons on. The response repeats the sent value and does not read the stored one. To read the stored value, use the `showQuickActions` field of `GET api/2.0/files/settings`.
