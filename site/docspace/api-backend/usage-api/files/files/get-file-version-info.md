# getFileVersionInfo

> FileArrayWrapper getFileVersionInfo(fileId)

`GET /api/2.0/files/file/{fileId}/history`

Get file versions

Returns every stored version of a file, newest first, each in the shape of a file. Unlike the list of `GET api/2.0/files/file/{fileId}/edit/history`, this list includes the autosaves of editing sessions. Requires the right to read the file history. Other callers get 403, including a DocSpace admin with only read access and an anonymous caller. In a room, a room manager and a content creator have this right. In a personal section, editing access is enough. The call is read-only. If no file has this id, the call also returns 403. If `fileId` is neither a number nor the id of a third-party file, the call returns 404. To restore a version, use `POST api/2.0/files/file/{fileId}/restoreversion`. To close or reopen a revision group, use `PUT api/2.0/files/file/{fileId}/history`.
