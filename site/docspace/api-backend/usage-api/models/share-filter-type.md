# ShareFilterType
[0 - User or group, 1 - Invitation link, 2 - External link, 4 - Additional external link, 8 - Primary external link, 16 - User, 32 - Group]

- `0` (`UserOrGroup`)
- `1` (`InvitationLink`)
- `2` (`ExternalLink`)
- `4` (`AdditionalExternalLink`)
- `8` (`PrimaryExternalLink`)
- `15` (`Link`)
- `16` (`User`)
- `32` (`Group`)
