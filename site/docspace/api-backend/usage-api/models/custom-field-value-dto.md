# CustomFieldValueDto
The custom text field of an entry: a free-form name with its value. Custom fields belong to no template, need no assignment and are addressed by name.

|------------ | ------------- | ------------- | -------------|
| **name** | **String** | The field name. | [optional] [example: `Project code`] [nullable] |
| **value** | **String** | The field value on the entry. | [optional] [example: `A-42`] [nullable] |
