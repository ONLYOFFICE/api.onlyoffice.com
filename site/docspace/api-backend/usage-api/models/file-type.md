# FileType

Possible values:

- `0` - Unknown (`Unknown`)
- `1` - Archive (`Archive`)
- `2` - Video (`Video`)
- `3` - Audio (`Audio`)
- `4` - Image (`Image`)
- `5` - Spreadsheet (`Spreadsheet`)
- `6` - Presentation (`Presentation`)
- `7` - Document (`Document`)
- `10` - Pdf (`Pdf`)
- `11` - Diagram (`Diagram`)
