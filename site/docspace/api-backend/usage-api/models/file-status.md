# FileStatus

Possible values:

- `0` - None (`None`)
- `1` - Is editing (`IsEditing`)
- `2` - Is new (`IsNew`)
- `4` - Is converting (`IsConverting`)
- `8` - Is original (`IsOriginal`)
- `16` - Is editing alone (`IsEditingAlone`)
- `32` - Is favorite (`IsFavorite`)
- `64` - Is template (`IsTemplate`)
- `128` - Is fill form draft (`IsFillFormDraft`)
- `256` - Is completed form (`IsCompletedForm`)
