# ProviderFilter

Possible values:

- `0` - None (`None`)
- `1` - Box (`Box`)
- `2` - DropBox (`DropBox`)
- `3` - GoogleDrive (`GoogleDrive`)
- `4` - kDrive (`kDrive`)
- `5` - OneDrive (`OneDrive`)
- `6` - SharePoint (`SharePoint`)
- `7` - WebDav (`WebDav`)
- `8` - Yandex (`Yandex`)
- `9` - Storage (`Storage`)
