# SubjectType

Possible values:

- `0` - User (`User`)
- `1` - External link (`ExternalLink`)
- `2` - Group (`Group`)
- `3` - Invitation link (`InvitationLink`)
- `4` - Primary external link (`PrimaryExternalLink`)
- `5` - Read access to a room linked to an AI project the user is a member of (`AiProject`)
