# AiActionType
The AI action a request or an assignment applies to. Each action has its own assignment slot; `Default` is the profile used when an action's own slot is empty.

Possible values:

- `Default`
- `Chat`
- `Code`
- `Summarization`
- `Translation`
- `TextAnalyze`
- `ImageGeneration`
- `OCR`
- `Vision`
