# SDKs

The ONLYOFFICE Apps SDKs are libraries that provide tools for integrating and managing ONLYOFFICE Apps features within your applications. This simplifies interaction with the ONLYOFFICE Apps backend REST API by offering ready-to-use methods and models. These SDKs support a number of popular programming languages.
