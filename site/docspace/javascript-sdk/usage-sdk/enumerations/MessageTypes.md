# MessageTypes

The types of messages exchanged between SDK components and the host application.

## Enumeration Members

<APITable>

| Enumeration Member | Value | Description |
| ------ | ------ | ------ |
| `Error` | `"error"` | The message sent when an error occurs. |
| `OnCallCommand` | `"onCallCommand"` | The message sent when a command is called. |
| `OnEventReturn` | `"onEventReturn"` | The message sent when an event occurs. |
| `OnMethodReturn` | `"onMethodReturn"` | The message sent when a method returns a result. |

</APITable>
