# FilterSortOrder

The sort direction for file/folder lists. Passed via [TFrameFilter.sortOrder](../type-aliases/TFrameFilter.md#sortOrder).

## Enumeration Members

<APITable>

| Enumeration Member | Value | Description |
| ------ | ------ | ------ |
| `Ascending` | `"ascending"` | A-Z, oldest first, smallest first. |
| `Descending` | `"descending"` | Z-A, newest first, largest first. |

</APITable>
