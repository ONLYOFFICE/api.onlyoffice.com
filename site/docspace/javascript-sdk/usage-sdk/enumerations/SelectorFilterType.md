# SelectorFilterType

The filter type used in the selector views.

## Enumeration Members

<APITable>

| Enumeration Member | Value | Description |
| ------ | ------ | ------ |
| `All` | `"all"` | Shows all available items. |
| `RoomsOnly` | `"roomsOnly"` | Shows only rooms. |
| `UserOnly` | `"userFolderOnly"` | Shows only user folders. |

</APITable>
