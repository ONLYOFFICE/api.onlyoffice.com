# Classes

The classes an integration works with. `SDK` creates frames and keeps them in a registry, `SDKInstance` drives one embedded iframe and exposes the methods that call into it.

## Overview

The following classes are available:

| Class | Description |
| --- | --- |
| [`SDK`](SDK.md) | The SDK class is responsible for managing multiple `SDKInstance` objects. |
| [`SDKInstance`](SDKInstance.md) | Represents an SDK instance for managing frames and communicating with DocSpace. |
