# Variables

Exported constants: the default frame configuration, the iframe name prefix, the CSP validation endpoint and the error messages the SDK shows.

## Overview

The following constants are available:

| Constant | Description |
| --- | --- |
| [`connectErrorText`](connectErrorText.md) | The error message displayed when the message bus fails to connect with the embedded frame. |
| [`CSPApiUrl`](CSPApiUrl.md) | The API endpoint for managing Content Security Policy (CSP) settings. |
| [`cspErrorText`](cspErrorText.md) | The error message displayed when the current domain is not included in the CSP settings. |
| [`defaultConfig`](defaultConfig.md) | The default configuration object for initializing and embedding a DocSpace frame. |
| [`FRAME_NAME`](FRAME_NAME.md) | The default name for the DocSpace iframe element. |
