# Type Aliases

Configuration, event, filter and data shapes exchanged with the embedded frame. Most integrations only need `TFrameConfig` and `TFrameEvents`; the remaining types describe what the instance methods accept and return.

## Overview

The following types are available:

| Type | Description |
| --- | --- |
| [`TBannerDisplaying`](TBannerDisplaying.md) | The template literal type for the display options of the header banner. |
| [`TEditorCustomization`](TEditorCustomization.md) | The editor customization configuration. |
| [`TEditorType`](TEditorType.md) | The template literal type based on the `EditorType` enum. |
| [`TEventReturnData`](TEventReturnData.md) | The event return data structure. |
| [`TFilterSortBy`](TFilterSortBy.md) | The template literal type representing the filter sort options. |
| [`TFilterSortOrder`](TFilterSortOrder.md) | The template literal type representing the filter sort order. |
| [`TFrameConfig`](TFrameConfig.md) | The frame configuration. |
| [`TFrameEvents`](TFrameEvents.md) | The frame event handlers. |
| [`TFrameFilter`](TFrameFilter.md) | The frame filter criteria. |
| [`TFrameMode`](TFrameMode.md) | The template literal type representing the frame mode based on `SDKMode`. |
| [`TManagerViewMode`](TManagerViewMode.md) | The template literal type representing the manager view mode. |
| [`TMessageData`](TMessageData.md) | The message data structure. |
| [`TMessageTypes`](TMessageTypes.md) | The template literal type for message types. |
| [`TSelectorType`](TSelectorType.md) | The template literal type for the selector filters. |
| [`TTask`](TTask.md) | The task object structure. |
| [`TTheme`](TTheme.md) | The template literal type representing the theme options. |
