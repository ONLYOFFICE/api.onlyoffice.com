# TGetExternalDataRequest

Payload the ONLYOFFICE Apps iframe sends when it asks the host to read a value from external storage.
Passed to [TFrameEvents.onGetExternalData](TFrameEvents.md#onGetExternalData).

The meaning of `key` is defined by the integrator — it is the identifier used on the
integrator side to address a specific record in the host's own storage.

```ts
type TGetExternalDataRequest = object;
```

## Properties

<APITable>

| Property | Type | Description |
| ------ | ------ | ------ |
| `callId` | `number` | Correlation ID generated by the iframe. The SDK echoes it back in the response envelope so the iframe can match parallel requests. |
| `key` | `string` | Identifier defined by the integrator. Addresses the record the iframe wants to read. |

</APITable>
