# TSelectorType

String literal union of all [SelectorFilterType](../enumerations/SelectorFilterType.md) values.

Accepted by [TFrameConfig.selectorType](TFrameConfig.md#selectorType) in [SDKMode.FileSelector](../enumerations/SDKMode.md#FileSelector) mode.
Using the [SelectorFilterType](../enumerations/SelectorFilterType.md) enum constants is preferred.

```ts
type TSelectorType = `${SelectorFilterType}`;
```
