# UI

The components themselves, grouped by what they do on a page: controls, overlays, data display, navigation, feedback and layout.

## Overview

The groups are:

| Group | Description |
| --- | --- |
| [Form controls](./form-controls/index.md) | Inputs, pickers and the containers that label them. |
| [Interactive elements](./interactive-elements/index.md) | Buttons in their variants -- plain, icon, floating, main-menu -- and the drag-and-drop surfaces: components whose job is to be clicked or dragged. |
| [Status components](./status-components/index.md) | Loaders and progress: spinners, the full-screen application loader, the infinite-scroll loader and the progress bar. |
| [Layout](./layout/index.md) | The page's plumbing: portals, scroll areas, the selection rectangle and the theme wrapper. |
| [Layout components](./layout-components/index.md) | Screens for the moments a view has nothing to show: an empty folder, a search with no results, an error. |
| [Overlays](./overlays/index.md) | Everything drawn above the page: modal dialogs and side panels, drop-downs and context menus, tooltips and the selector. |
| [Data display](./data-display/index.md) | Components that show a value rather than take one: text and headings, avatars, badges and tags, room icons and logos, and cards. |
| [Skeletons](./skeletons/index.md) | Placeholder shapes shown while content loads, so the layout does not jump when it arrives. |
| [Feedback](./feedback/index.md) | Components that tell the user what happened or what is happening: toasts and snack bars, status messages, info bars and progress for long operations. |
| [Navigation](./navigation/index.md) | Links, tabs, paging and the side menu that moves the user between views. |
| [Rows](./rows/index.md) | The row-based list the portal shows files and rooms in, with its container and content layout. |
| [Table](./table/index.md) | The data table with resizable columns, its header, rows and group menu. |
| [Tiles](./tiles/index.md) | The tile grid: a container, the base tile and the file, folder, room and template tiles built on it. |
