# Feedback

Components that tell the user what happened or what is happening: toasts and snack bars, status messages, info bars and progress for long operations.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`ColumnarInfoBar`](./columnar-info-bar.md) | Bar of label-and-value columns for context the reader does not have to act on. |
| [`LoadingButton`](./loading-button.md) | 16px progress ring with a cross in the middle, for cancelling what it is measuring. |
| [`OperationsProgressButton`](./operations-progress-button.md) | Corner badge that reports every background operation of the portal and lists them when there is more than one. |
| [`PublicRoomBar`](./public-room-bar.md) | Grey note above a screen's content: an icon, a bold line and a paragraph, with an optional close cross. |
| [`SnackBar`](./snackbar.md) | Full-width notification bar that sits at the top of a section until it is dismissed. |
| [`StatusMessage`](./status-message.md) | A full-width bar with a danger glyph that fades one message out before fading the next one in. |
| [`Toast`](./toast.md) | Container the transient notifications are stacked in, driven by the imperative `toastr`. |
| [`TopLoader`](./top-loading-indicator.md) | The thin bar at the top of the page, driven by three static calls rather than by React. |
