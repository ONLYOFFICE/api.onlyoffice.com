# Status components

Loaders and progress: spinners, the full-screen application loader, the infinite-scroll loader and the progress bar.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`AppLoader`](./app-loader.md) | The blank first screen: a fixed sheet over the whole viewport with the kit's rombs animation on it. |
| [`InfiniteLoader`](./infinite-loader.md) | Virtualised list or grid that asks for the next page as the user scrolls towards the end. |
| [`LoaderWrapper`](./loader-wrapper.md) | Dims whatever is inside it and stops the mouse reaching it while something is loading. |
| [`Loader`](./loader.md) | Spinner in one of four animations, for work whose duration is unknown. |
| [`ProgressBar`](./progress-bar.md) | A labelled bar for an operation whose progress you can measure, with a status or error line under it. |
