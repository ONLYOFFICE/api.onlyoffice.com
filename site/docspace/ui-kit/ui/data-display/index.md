# Data display

Components that show a value rather than take one: text and headings, avatars, badges and tags, room icons and logos, and cards.

## Overview

The following components are available:

| Component | Description |
| --- | --- |
| [`Avatar`](./avatar.md) | Round picture of a person or a group, falling back to initials, with an optional role badge and an edit menu. |
| [`Badge`](./badge.md) | Small coloured pill for a count or a short marker, announced as a live status region. |
| [`Card`](./card.md) | Grey panel with an optional header row, for a block of related information. |
| [`CategoryItem`](./category-item.md) | Settings-page entry: a linked title, a line of explanation, an arrow, and an optional paid badge. |
| [`CollapsibleCard`](./collapsible-card.md) | Panel whose header is a button that expands and collapses the body under it. |
| [`Heading`](./heading.md) | Section title rendered as a real heading element, sized by a preset rather than by its level. |
| [`MCPIcon`](./mcp-icon.md) | Square icon for an MCP server: its logo, or the first letter of its name on a grey tile. |
| [`PortalLogo`](./portal-logo.md) | The portal's white-label logo, fetched from the DocSpace server and swapped for the theme. |
| [`QuickActions`](./quick-actions.md) | Horizontal strip of large icon tiles that scrolls when the tiles no longer fit. |
| [`RoomIcon`](./room-icon.md) | Square room tile that shows the room's logo, or its initials on a colour when there is none. |
| [`RoomLogo`](./room-logo.md) | Fixed 32px glyph saying which kind of room this is, with an optional selection checkbox. |
| [`RoomType`](./room-type.md) | Row offering one kind of room, with its glyph, its translated name and its description. |
| [`SelectedItem`](./selected-item.md) | Chip with a cross, for a value the user has picked and can take back. |
| [`Tag`](./tag.md) | Small outlined label for one keyword, clickable and optionally removable. |
| [`Tags`](./tags.md) | One row of tags that keeps to its width, collapsing the rest into an overflow tag. |
| [`Text`](./text.md) | Body text at the kit's size and weight, rendered through whichever element you name. |
