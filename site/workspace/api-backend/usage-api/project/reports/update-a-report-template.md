**PUT** `/api/2.0/project/report/{reportid:[0-9]+}`

Updates the selected project report template with the parameters specified in the request.

## Request body

### reportid

**type:** `integer`

Report template ID

**Example**: `0`

### name

**type:** `string`

New report name

**Example**: `"string"`

### period

**type:** `string`

New report generation period: Day/Week/Month

**Example**: `"string"`

### periodItem

**type:** `integer`

New period item: day of the week (for a weekly report, starting with Sunday), day of the month (for a monthly report)

**Example**: `0`

### hour

**type:** `integer`

New report sending time (in hours)

**Example**: `0`

### autoGenerated

**type:** `boolean`

Specifies if a report will be automatically generated or not

**Example**: `true`

### reportType

**type:** `integer`

New report type

**Example**: `0`

### tag

**type:** `integer`

New report tag

**Example**: `0`

### project

**type:** `integer`

New report project

**Example**: `0`

### status

**type:** `integer[]`

New task status

### departament

**type:** `string`

New department/group GUID

**Example**: `"string"`

### userId

**type:** `string`

New user GUID

**Example**: `"string"`

### reportTimeInterval

**type:** `integer`

New report time interval

**Example**: `0`

### fromDate

**type:** `string`

New report period start date

**Example**: `"string"`

### toDate

**type:** `string`

New report period end date

**Example**: `"string"`

### viewType

**type:** `integer`

New view type: by group or by project

**Example**: `0`

### noResponsible

**type:** `boolean`

Specifies if the tasks without responsibles will be shown or hidden

**Example**: `true`

## Request example

```json
{
  "reportid": 0,
  "name": "string",

  "periodItem": 0,

  "autoGenerated": true,

  "project": 0,
  "status": [
    0
  ],
  "departament": "string",
  "userId": "string",
  "reportTimeInterval": 0,
  "fromDate": "string",
  "toDate": "string",
  "viewType": 0,
  "noResponsible": true
}
```
