**POST** `/api/2.0/people/{userid}/contacts`

Sets the contacts of the user with the ID specified in the request replacing the current portal data with the new data.

## Path parameters

### userid

**type:** `string`

User ID

**Example**: `"string"`

## Request body

### contacts

**type:** `Contact[]`

List of new contacts

## Request example

```json
{
  "contacts": [
    {
      "Type": "GTalk",
      "Value": "my@gmail.com"
    }
  ]
}
```

## Returns

Updated user profile. A request that is not authenticated returns `401`.
