**PUT** `/api/2.0/people/remove/terminate`

Terminates the data deletion for the user with the ID specified in the request.

## Request body

### userId

**type:** `string`

User ID

**Example**: `"string"`

## Request example

```json
{
  "userId": "string"
}
```
