**PUT** `/api/2.0/crm/opportunity`

Deletes a group of opportunities with the IDs specified in the request.

## Request body

### opportunityids

**type:** `integer[]`

List of opportunity IDs

## Request example

```json
{
  "opportunityids": [
    0
  ]
}
```

## Returns

List of opportunities. A request that is not authenticated returns `401`.
