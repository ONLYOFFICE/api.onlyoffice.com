**PUT** `/api/2.0/crm/invoice/settings/terms`

Saves the default settings for the invoice terms specified in the request.

## Request body

### terms

**type:** `string`

Invoice terms

**Example**: `"string"`

## Request example

```json
{
  "terms": "string"
}
```

## Returns

Invoice settings. A request that is not authenticated returns `401`.

### Autogenerated

**type:** `boolean`

**Example**: `true`

### Prefix

**type:** `string`

**Example**: `"Prefix"`

### Number

**type:** `string`

**Example**: `"Number"`

### Terms

**type:** `string`

**Example**: `"Terms"`

### CompanyName

**type:** `string`

**Example**: `"CompanyName"`

### CompanyLogoID

**type:** `integer`

**Example**: `123`

### CompanyAddress

**type:** `string`

**Example**: `"CompanyAddress"`

## Response example

```json
{
  "Autogenerated": true,
  "Prefix": "Prefix",
  "Number": "Number",
  "Terms": "Terms",
  "CompanyName": "CompanyName",
  "CompanyLogoID": 123,
  "CompanyAddress": "CompanyAddress"
}
```
