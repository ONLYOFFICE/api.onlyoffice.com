# AI

Connects an AI provider (e.g., OpenAI, DeepSeek) to ONLYOFFICE editors, enabling intelligent text generation, editing, summarization, and automatic macro creation.

**Supported editors:** documents, spreadsheets, presentations, PDF.

The AI plugin is now called **AI Tools**. To install, configure, and use AI Tools, see [AI Tools](../../ai/guides/ai-plugin.md). AI Tools is developed separately from the other plugins, and its source code is not publicly available.

The [old AI plugin](https://github.com/ONLYOFFICE/onlyoffice.github.io/tree/master/sdkjs-plugins/content/ai) is no longer supported and can be installed only in version 9.4.
