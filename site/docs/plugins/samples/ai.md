# AI

Connects an AI provider (e.g., OpenAI, DeepSeek) to ONLYOFFICE editors, enabling intelligent text generation, editing, summarization, and automatic macro creation.

**Supported editors:** documents, spreadsheets, presentations, PDF.

The AI plugin is now called **AI Tools**. It is developed separately from the other plugins and is not available as source code in the plugins repository. To install, configure, and use AI Tools, see [AI Tools](../../ai/guides/ai-plugin.md).
