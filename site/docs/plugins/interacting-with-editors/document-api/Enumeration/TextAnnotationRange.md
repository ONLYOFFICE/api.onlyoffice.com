# TextAnnotationRange

Defines a text range within a paragraph to be highlighted as an annotation.

## Type

Object

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| id | string | Unique identifier for the range. |
| length | number | Length of the text range. |
| name | string | Annotation type (e.g., `"grammar"`). |
| start | number | Starting index of the text range. |
