# SetButtonDisabled

Enables or disables the modal plugin footer button by index.

## Syntax

```javascript
expression.SetButtonDisabled(index, isDisabled);
```

`expression` - A variable that represents an [Api](../presentation-api.md) class.

## Parameters

| **Name** | **Required/Optional** | **Data type** | **Default** | **Description** |
| ------------- | ------------- | ------------- | ------------- | ------------- |
| index | Required | number |  | The button index (0-based) in the buttons array from config.json. |
| isDisabled | Required | boolean |  | Specifies whether to disable (true) or enable (false) the button. |

## Returns

This method doesn't return any data.
