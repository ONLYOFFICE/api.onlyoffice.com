# GetAction

Gets the action executed when the link is clicked. Changes to the returned action update the link.

## Syntax

```javascript
expression.GetAction();
```

`expression` - A variable that represents an [ApiLinkAnnotation](../ApiLinkAnnotation.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiBaseAction](../../ApiBaseAction/ApiBaseAction.md) \| null \| undefined
