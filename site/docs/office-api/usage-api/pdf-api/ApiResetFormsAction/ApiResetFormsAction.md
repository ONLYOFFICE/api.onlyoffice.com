| [GetNames](./Methods/GetNames.md) | string[] | Gets names of fields to reset |
| [IsAllExcept](./Methods/IsAllExcept.md) | boolean | Will all fields be reset except the fields whose names are specified |
| [SetAllExcept](./Methods/SetAllExcept.md) | boolean | Sets all fields be reset except the fields whose names are specified |
| [SetNames](./Methods/SetNames.md) | boolean | Sets names of fields to reset |
