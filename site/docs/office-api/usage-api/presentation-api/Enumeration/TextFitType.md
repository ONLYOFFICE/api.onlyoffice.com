# TextFitType

The available text autofit types inside a shape.

## Type

Enumeration

## Values

- "noAutoFit"
- "normAutoFit"
- "autoFit"

## Example

Set the autofit type that resizes the shape to fit its text.

```javascript editor-pptx
// Specify the text autofit behavior applied inside a shape.

// Apply the "autoFit" text fit type to the ApiShape object.

shape.SetTextFit("autoFit");
```
