# GetPageSetup

Returns the page setup object that represents the print layout settings of the current worksheet.

## Syntax

```javascript
expression.GetPageSetup();
```

`expression` - A variable that represents an [ApiWorksheet](../ApiWorksheet.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiPageSetup](../../ApiPageSetup/ApiPageSetup.md)
