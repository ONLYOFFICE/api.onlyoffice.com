# GetPivotFilters

Returns the collection of pivot filters applied to the specified pivot field.

Inherited from [ApiPivotField.GetPivotFilters](../../ApiPivotField/Methods/GetPivotFilters.md).

## Syntax

```javascript
expression.GetPivotFilters();
```

`expression` - A variable that represents an [ApiPivotDataField](../ApiPivotDataField.md) class.

## Parameters

This method doesn't have any parameters.

## Returns

[ApiPivotFilters](../../ApiPivotFilters/ApiPivotFilters.md)
