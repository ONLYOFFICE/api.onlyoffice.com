# ApiShd

Class representing the shading of text, a paragraph, a table or a table cell.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| Color | [ApiColor](../ApiColor/ApiColor.md) | The shading color. |
| Type | [ShdType](../Enumeration/ShdType.md) | The shading type: **"nil"** - no shading, **"clear"** - solid fill. |

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "shd" | Returns a type of the ApiShd class. |
| [GetColor](./Methods/GetColor.md) | [ApiColor](../ApiColor/ApiColor.md) \| null \| undefined | Returns the shading color. |
| [GetType](./Methods/GetType.md) | [ShdType](../Enumeration/ShdType.md) | Returns the shading type. |
