# ApiPage

Class representing the header and footer of a specific page type (even or first) of a worksheet.

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| CenterFooter | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | Returns the center footer section of this page type. |
| CenterHeader | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | Returns the center header section of this page type. |
| LeftFooter | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | Returns the left footer section of this page type. |
| LeftHeader | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | Returns the left header section of this page type. |
| RightFooter | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | Returns the right footer section of this page type. |
| RightHeader | [ApiHeaderFooter](../ApiHeaderFooter/ApiHeaderFooter.md) | Returns the right header section of this page type. |
