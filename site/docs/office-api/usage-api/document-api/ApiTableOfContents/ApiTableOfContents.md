# ApiTableOfContents

Class representing a table of contents.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](./Methods/Delete.md) | boolean | Removes the table of contents from the document. |
| [GetClassType](./Methods/GetClassType.md) | "tableOfContents" | Returns a type of the ApiTableOfContents class. |
| [GetIncludePageNumbers](./Methods/GetIncludePageNumbers.md) | boolean | Returns whether page numbers are shown in the table of contents. |
| [GetLowerHeadingLevel](./Methods/GetLowerHeadingLevel.md) | number | Returns the lowest (innermost) heading level included in the table of contents. |
| [GetParent](./Methods/GetParent.md) | [ApiDocument](../ApiDocument/ApiDocument.md) \| null | Returns the document that contains the table of contents. |
| [GetRange](./Methods/GetRange.md) | [ApiRange](../ApiRange/ApiRange.md) \| null | Returns a range that covers the entire table of contents. |
| [GetRightAlignPageNumbers](./Methods/GetRightAlignPageNumbers.md) | boolean | Returns whether page numbers are right-aligned in the table of contents. |
| [GetUpperHeadingLevel](./Methods/GetUpperHeadingLevel.md) | number | Returns the highest (outermost) heading level included in the table of contents. |
| [GetUseHyperlinks](./Methods/GetUseHyperlinks.md) | boolean | Returns whether entries are formatted as hyperlinks. |
| [SetIncludePageNumbers](./Methods/SetIncludePageNumbers.md) | boolean | Specifies whether page numbers are shown in the table of contents. |
| [SetLowerHeadingLevel](./Methods/SetLowerHeadingLevel.md) | boolean | Sets the lowest (innermost) heading level included in the table of contents. |
| [SetPr](./Methods/SetPr.md) | boolean | Applies the specified properties to the table of contents and rebuilds it. |
| [SetRightAlignPageNumbers](./Methods/SetRightAlignPageNumbers.md) | boolean | Specifies whether page numbers are right-aligned in the table of contents. |
| [SetUpperHeadingLevel](./Methods/SetUpperHeadingLevel.md) | boolean | Sets the highest (outermost) heading level included in the table of contents. |
| [SetUseHyperlinks](./Methods/SetUseHyperlinks.md) | boolean | Specifies whether entries are formatted as hyperlinks. |
| [Update](./Methods/Update.md) | boolean | Updates the table of contents. |
