# ComparisonPr

Document comparison and merge properties.

## Type

Object

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| authorName | string | The name to which the tracked changes are attributed. If not specified, the author of the second document is used. |
| caseChanges | boolean | Specifies whether to mark differences in case. |
| comments | boolean | Specifies whether to compare differences in comments. |
| footnotes | boolean | Specifies whether to compare differences in footnotes and endnotes. |
| formatting | boolean | Specifies whether to mark differences in formatting. |
| headersAndFooters | boolean | Specifies whether to compare differences in headers and footers. |
| tables | boolean | Specifies whether to compare differences in tables. |
| textBoxes | boolean | Specifies whether to compare differences in text boxes. |
| whiteSpace | boolean | Specifies whether to mark differences in white space. |
| words | boolean | Specifies whether changes are tracked by word (true) or by character (false). |
