# FormType

Form type.

The available form types.

## Type

Enumeration

## Values

- "textForm"
- "comboBoxForm"
- "dropDownForm"
- "checkBoxForm"
- "radioButtonForm"
- "pictureForm"
- "complexForm"
- "dateForm"
- "signatureForm"

## Example

Return the type of the current form.

```javascript editor-docx
// How do I get the type of a form?

// Return a type from the ApiTextForm object.

let formType = textForm.GetFormType();
```
