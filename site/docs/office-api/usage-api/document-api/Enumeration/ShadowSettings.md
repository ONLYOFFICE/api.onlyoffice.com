# ShadowSettings

Properties used to create a shadow.

## Type

Object

## Properties

| Name | Type | Description |
| ---- | ---- | ----------- |
| color | [ApiColor](../ApiColor/ApiColor.md) | The shadow color (black by default). |
| offsetX | number | The horizontal offset of the shadow measured in points (a positive value offsets to the right). |
| offsetY | number | The vertical offset of the shadow measured in points (a positive value offsets downwards). |
| rotateWithShape | boolean | Specifies whether the shadow rotates together with the shape. |
| size | number | The shadow size as a percentage of the shape size. |
| transparency | number | The shadow transparency from 0.0 (opaque) to 1.0 (clear). |
