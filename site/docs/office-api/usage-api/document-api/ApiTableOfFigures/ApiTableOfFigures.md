# ApiTableOfFigures

Class representing a table of figures.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Delete](./Methods/Delete.md) | boolean | Removes the table of figures from the document. |
| [GetCaption](./Methods/GetCaption.md) | string \| null | Returns the caption label that the table of figures is built from (for example, "Figure"). |
| [GetClassType](./Methods/GetClassType.md) | "tableOfFigures" | Returns a type of the ApiTableOfFigures class. |
| [GetIncludeLabel](./Methods/GetIncludeLabel.md) | boolean | Returns whether the caption label and number are included in the table of figures entries. |
| [GetIncludePageNumbers](./Methods/GetIncludePageNumbers.md) | boolean | Returns whether page numbers are shown in the table of figures. |
| [GetParent](./Methods/GetParent.md) | [ApiDocument](../ApiDocument/ApiDocument.md) \| null | Returns the document that contains the table of figures. |
| [GetRange](./Methods/GetRange.md) | [ApiRange](../ApiRange/ApiRange.md) \| null | Returns a range that covers the entire table of figures. |
| [GetRightAlignPageNumbers](./Methods/GetRightAlignPageNumbers.md) | boolean | Returns whether page numbers are right-aligned in the table of figures. |
| [GetUseHyperlinks](./Methods/GetUseHyperlinks.md) | boolean | Returns whether entries are formatted as hyperlinks. |
| [SetCaption](./Methods/SetCaption.md) | boolean | Sets the caption label that the table of figures is built from (for example, "Figure"). |
| [SetIncludeLabel](./Methods/SetIncludeLabel.md) | boolean | Specifies whether the caption label and number are included in the table of figures entries. |
| [SetIncludePageNumbers](./Methods/SetIncludePageNumbers.md) | boolean | Specifies whether page numbers are shown in the table of figures. |
| [SetPr](./Methods/SetPr.md) | boolean | Applies the specified properties to the table of figures and rebuilds it. |
| [SetRightAlignPageNumbers](./Methods/SetRightAlignPageNumbers.md) | boolean | Specifies whether page numbers are right-aligned in the table of figures. |
| [SetUseHyperlinks](./Methods/SetUseHyperlinks.md) | boolean | Specifies whether entries are formatted as hyperlinks. |
| [Update](./Methods/Update.md) | boolean | Updates the table of figures. |
