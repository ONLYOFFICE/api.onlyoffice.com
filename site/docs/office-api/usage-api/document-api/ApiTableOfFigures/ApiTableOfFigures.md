# ApiTableOfFigures

Class representing a table of figures.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetCaption](./Methods/GetCaption.md) | string \| null | Returns the caption label that the table of figures is built from (for example, "Figure"). |
| [GetClassType](./Methods/GetClassType.md) | "tableofcontents" | Returns a type of the ApiTableOfFigures class. |
| [GetIncludeLabel](./Methods/GetIncludeLabel.md) | boolean | Returns whether the caption label and number are included in the table of figures entries. |
| [SetCaption](./Methods/SetCaption.md) | boolean | Sets the caption label that the table of figures is built from (for example, "Figure"). |
| [SetIncludeLabel](./Methods/SetIncludeLabel.md) | boolean | Specifies whether the caption label and number are included in the table of figures entries. |
| [SetPr](./Methods/SetPr.md) | boolean | Applies the specified properties to the table of figures and rebuilds it. |
