| [GetWidth](./Methods/GetWidth.md) | [EMU](../Enumeration/EMU.md) \| null | Gets the width of the stroke in English Metric Units. |
| [SetBeginArrow](./Methods/SetBeginArrow.md) | boolean | Sets the beginning arrow of the stroke. |
