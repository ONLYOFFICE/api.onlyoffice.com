# ApiMath

Class representing a mathematical equation.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "math" | Returns a type of the ApiMath class. |
| [GetParent](./Methods/GetParent.md) | [ParagraphLikeContainer](../Enumeration/ParagraphLikeContainer.md) \| null \| undefined | Returns the parent element (a paragraph or an inline content control) that directly contains the current math element. |
| [GetPosInParent](./Methods/GetPosInParent.md) | Number | Returns the position (index) of the current math element within its parent element. |
| [GetText](./Methods/GetText.md) | string | Returns the inner text of the current math element. |
