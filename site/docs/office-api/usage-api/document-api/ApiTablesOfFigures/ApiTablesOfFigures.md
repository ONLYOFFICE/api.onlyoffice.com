# ApiTablesOfFigures

Class representing the collection of all tables of figures in a document.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](./Methods/Add.md) | [ApiTableOfFigures](../ApiTableOfFigures/ApiTableOfFigures.md) \| null | Adds a table of figures to the document and returns it. |
| [GetClassType](./Methods/GetClassType.md) | "tablesOfFigures" | Returns a type of the ApiTablesOfFigures class. |
| [GetCount](./Methods/GetCount.md) | number | Returns the number of tables of figures in the document. |
| [GetItem](./Methods/GetItem.md) | [ApiTableOfFigures](../ApiTableOfFigures/ApiTableOfFigures.md) \| null | Returns the table of figures at the specified position in the collection. |
| [GetParent](./Methods/GetParent.md) | [ApiDocument](../ApiDocument/ApiDocument.md) | Returns the document that owns this collection. |
