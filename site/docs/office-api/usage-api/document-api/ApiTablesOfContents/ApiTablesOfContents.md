# ApiTablesOfContents

Class representing the collection of all tables of contents in a document.

:::note
This functionality is available in paid ONLYOFFICE Docs editions.
:::

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [Add](./Methods/Add.md) | [ApiTableOfContents](../ApiTableOfContents/ApiTableOfContents.md) \| null | Adds a table of contents to the document and returns it. |
| [GetClassType](./Methods/GetClassType.md) | "tablesOfContents" | Returns a type of the ApiTablesOfContents class. |
| [GetCount](./Methods/GetCount.md) | number | Returns the number of tables of contents in the document. |
| [GetItem](./Methods/GetItem.md) | [ApiTableOfContents](../ApiTableOfContents/ApiTableOfContents.md) \| null | Returns the table of contents at the specified position in the collection. |
| [GetParent](./Methods/GetParent.md) | [ApiDocument](../ApiDocument/ApiDocument.md) | Returns the document that owns this collection. |
