# ApiFill

Class representing a base class for fill.

## Methods

The following table lists the available methods.

| Method | Returns | Description |
| ------ | ------- | ----------- |
| [GetClassType](./Methods/GetClassType.md) | "fill" | Returns a type of the ApiFill class. |
| [GetColor](./Methods/GetColor.md) | [ApiColor](../ApiColor/ApiColor.md) \| null \| undefined | Returns the color of a solid fill. |
| [GetTransparent](./Methods/GetTransparent.md) | number | Returns the transparency of the fill. |
| [GetType](./Methods/GetType.md) | [FillType](../Enumeration/FillType.md) | Gets the fill type. |
| [SetTransparent](./Methods/SetTransparent.md) | boolean | Sets the transparency of the fill. |
| [ToJSON](./Methods/ToJSON.md) | JSON | Converts the ApiFill object into the JSON object. |
